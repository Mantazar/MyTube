# MyTube

واجهة عربية أولية لمشروع مشاهدة وبحث فيديوهات، مصممة للنشر على GitHub Pages.

## التشغيل محلياً
افتح المشروع عبر خادم ملفات محلي يدعم ES Modules، مثل إضافة Live Server في محرر يدعمها. فتح `index.html` مباشرة قد لا يعمل بسبب قيود المتصفح.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى المستودع `MyTube`.
2. افتح Settings → Pages.
3. اختر Deploy from a branch.
4. اختر `main` والمجلد `/ (root)` ثم Save.
5. انتظر اكتمال النشر.

## إعداد مصدر Piped
من داخل الموقع افتح ⚙ الإعدادات وأدخل عنوان مصدر Piped API موثوقاً ومتوافقاً. يجب أن يسمح المصدر بطلبات المتصفح (CORS). قد تتوقف المصادر العامة أو تتغير واجهاتها.

## الموجود حالياً
- واجهة متجاوبة باللغة العربية.
- بحث عبر Piped API بعد إعداد المصدر.
- محاولة تشغيل الفيديو من روابط المصدر المتاحة.
- حفظ المفضلة والاشتراكات وسجل المشاهدة محلياً عبر IndexedDB.
- تصدير واستيراد نسخة JSON.

## ملاحظات وحدود
- هذا إصدار تأسيسي، وليس بديلاً كاملاً عن YouTube.
- GitHub Pages يستضيف ملفات الواجهة فقط؛ لا يشغّل خادماً خلفياً أو مهاماً دورية.
- بيانات IndexedDB مرتبطة بالمتصفح والجهاز وقد تُحذف إذا مسحت بيانات الموقع.
- بعض صيغ الفيديو تتطلب دمج الصوت والفيديو أو مشغلاً متخصصاً؛ هذا الإصدار لا يدمج المسارات المنفصلة.
- لا تضع مفاتيح API سرية في ملفات JavaScript المنشورة للعامة.
- استخدم المصادر وفق شروطها وقوانين بلدك، واحترم حقوق أصحاب المحتوى.

## خارطة الطريق
1. فحص توافق المصادر وإضافة قائمة مصادر احتياطية.
2. تحسين استخراج معرف الفيديو والتعامل مع تغييرات Piped API.
3. إضافة مشغل HLS/DASH عند الحاجة.
4. تحسين صفحة القناة والتوصيات.
5. إضافة اختبارات ورسائل تشخيص واضحة.
